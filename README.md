# 今天吃什么

公开页面展示食堂菜单快照，并提供填写点评、通过 GitHub Pull Request 提交评价的表单。菜单每月第一天（北京时间）更新一次；价格和在售情况以实际供应为准，快照不是实时库存。

页面：<https://94yi.github.io/bupt-shahe-menu/>

## 提交点评

打开页面，选择食堂、窗口、菜品，填写评分与体验，然后点击“去 GitHub 提交 PR”。GitHub 会引导你 fork 仓库并创建 Pull Request。若预填内容没有出现，页面也会给出可复制的 JSON；请把它存为 `reviews/<唯一名称>.json` 再提 PR。

“这顿吃什么”按钮读取同一份月度菜单；可先选择食堂、窗口、餐次，也可留空从全部菜单挑选。已合并的点评会影响推荐权重。推荐仅供参考，不代表当天有货。

表单不要求填写个人身份编号、手机号或真实姓名；PR 作者的 GitHub 账号会按 GitHub 的公开规则显示。请不要在点评中写自己或他人的个人信息。

每份评价是独立 JSON 文件，合并前由校验脚本检查字段与长度，再由维护者审阅内容。菜单数据文件 `data/menu.json` 由自动任务更新；请勿在点评 PR 中改动它。

## 菜单更新

工作流每月 1 日 00:00 UTC（北京时间 08:00）执行 `scripts/update_menu.py`。它只调用网站的窗口和菜品只读接口，并只保留目标区域的食堂、窗口、菜品、分类和价格。登录凭据放在更新工作流配置的仓库 Actions Secret 中，不会进入公开文件。也可以手动触发工作流；当天餐次为空时尝试查询次日菜单，页面标明对应菜单日期。窗口查询部分失败或午餐、晚餐均缺失时保留上一份快照。午餐或晚餐缺失时，页面可参考另一餐次的常规菜单，并明确提示实际供应为准。

本项目不提供下单、支付或购物车操作，为独立维护的社区项目。
